# EKS · Tres nodos administrados

Reserva tres nodos deseados con discos gp3 de 40 GiB. Conserva el endpoint privado y los controles del perfil estándar.

Copia `terraform.tfvars.example` a `terraform.tfvars` y reemplaza los identificadores por recursos existentes. Revisa los [prerrequisitos](../../README.md#prerrequisitos) y los [costos](../../README.md#costo-aproximado).
