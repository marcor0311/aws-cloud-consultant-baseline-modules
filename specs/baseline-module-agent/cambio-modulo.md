# Especificación de cambio de módulo

Copiar esta plantilla a la rama del cambio cuando se necesite conservar el diseño fuera del issue. Enlazar la especificación desde el PR.

| Campo | Qué registrar |
| --- | --- |
| Origen y elección | Issue del consumidor, requisito, opciones presentadas y decisión del arquitecto. |
| Alcance | Módulo, perfil, alta, actualización o retiro, referencia de partida y versión candidata. |
| Contrato | Entradas, salidas, dependencias, defaults seguros, políticas aplicables y ejemplos afectados. |
| Aceptación | Comportamiento observable, pruebas simuladas, controles que se verificarán y criterios de compatibilidad. |
| Impacto | Consumidores encontrados y alcance de búsqueda, efecto sobre estado, posibles reemplazos y migración. |
| Costo | Dimensiones de uso y dependencias, estimación antes y después bajo supuestos comparables. |
| Implementación | Tareas de Terraform, documentación, catálogo, pruebas y CI afectada. |
| Evidencia | Resultados y fecha, revisión exacta, enlaces al PR y a la decisión del arquitecto. |
